# Media provenance

All raster imagery in `public/media/` was created specifically for this fictional FORGE Athletic Club portfolio concept using the built-in OpenAI image generation tool on 12 October 2026. No third-party stock photos, external image URLs, real trainer likenesses, or video clips are included. The images are illustrative generated visualizations, not photographs documenting a real gym, a real location, or real employees.

The generated outputs were copied into the project and encoded as WebP. The facility images are 1200 × 800, the hero is 1672 × 941, and the trainer sheet is 1536 × 1024. Keep the portfolio disclosure when reusing these images in the site. These assets are supplied as part of this project; no separate stock-photo attribution is required. This file records provenance, and does not assert exclusive copyright over AI-generated output.

The source generator's applicable terms govern generated output. No Unsplash, Pexels, or other stock license is represented by these files. Stock imagery was researched but was not used.
